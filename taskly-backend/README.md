# Taskly Backend (NestJS)

The API workspace of Taskly. Setup, configuration, architecture and the endpoint reference are documented in the [root README](../README.md).

| Goal               | Command                    |
| ------------------ | -------------------------- |
| Run in development | `npm run start:dev`        |
| Build              | `npm run build`            |
| Run in production  | `npm run start:prod`       |
| Apply migrations   | `npm run migrate`          |
| Seed demo data     | `npm run seed`             |
| Unit tests         | `npm run test:unit`        |
| Integration tests  | `npm run test:integration` |
| End-to-end tests   | `npm run test:e2e`         |
| Lint and format    | `npm run lint` · `npm run format:check` |
